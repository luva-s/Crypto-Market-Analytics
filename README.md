# Crypto Market Analytics

Ein Python-Projekt zur Analyse von Kryptowährungsdaten über eine öffentliche API.

## 🎯 Ziel

Das Projekt soll praktische Erfahrungen mit **Python, APIs, Pandas und Datenvisualisierung** vermitteln.

Analysiert werden unter anderem:

* Durchschnittlicher Kurs
* Höchster / niedrigster Kurs
* Tagesrenditen
* Beste / schlechteste Tage
* Kursentwicklung

## 🛠️ Technologien

* Python
* Requests
* Pandas
* Matplotlib
* Git / GitHub


## 🎓 Lernziel

Python und grundlegende Data-Engineering-Konzepte anhand eines realen Datenprojekts praktisch lernen.
